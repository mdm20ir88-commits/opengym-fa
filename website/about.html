About openGym-fa

openGym-fa is the Persian and English self-hosted training platform created and maintained by Arta under the GitHub identity Jenesyx.

The project is built around a direct idea: your workouts, body-weight history and training plans should stay under your control. It runs on infrastructure you choose, supports browser-only guest use, and can synchronize profiles with secure passkeys.

The Persian edition adds a complete right-to-left interface while keeping English and the other supported languages available. The same repository contains the web app, API, Docker deployment, mobile shells and bilingual setup documentation.

The project remains free and open source under the AGPL. There is no subscription, advertising or telemetry, and users can export their data whenever they want.

— Arta (Jenesyx)

Principles

  • Your data is yours. Local-first, one-file backups, no lock-in — leaving openGym must always be one export away.
  • No telemetry, ever. If a feature needs analytics to justify itself, it doesn't ship.
  • Dependency-light. The backend is one Node file with a single dependency; the frontend is React, a router and a store. Small enough to actually audit.
  • Open source that stays open. AGPL-3.0, so every fork and every hosted version owes its code back to everyone.
